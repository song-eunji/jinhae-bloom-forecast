# 진해벚꽃 개화 예측 — 2026 창원시 AI·데이터 활용 공모전

적산온도(degree-day) 모델로 진해군항제 벚꽃 개화·만발일을 예측하고, 이를 바탕으로 축제 시기를 미리 가늠할 수 있는 인터랙티브 데모와 분석 자료입니다.

## 🔗 라이브 데모

**https://song-eunji.github.io/jinhae-bloom-forecast/**

- ① 연도별 모델 검증 (leave-one-out 교차검증)
- ② 일별 기온을 입력/CSV 업로드하면 개화·만발 예상일과 축제 추천기간을 계산
- ③ 전국 33개 관측지점 개화전선과 창원의 위치 비교

## 🧮 방법론 요약

- **모델**: 매년 2월 10일(개화 기준) / 2월 15일(만발 기준)부터 일평균기온의 기저온도 초과분을 누적, 임계값 도달일을 예측일로 산정하는 적산온도(degree-day) 모델
- **검증**: 2000~2026년 27개년 데이터로 leave-one-out 교차검증(LOOCV) — 특정 연도를 제외한 나머지 연도 평균으로 임계값을 학습해 그 해를 예측
- **나우캐스팅**: 시즌 중 실측 기온을 입력하면, 아직 관측되지 않은 이후 날짜는 평년(2000~2026년 동일 날짜) 평균 기온으로 채워 예측을 갱신
- **축제 추천기간**: 만발 예측일 기준 −5일~+4일(실제 축제 기간과 비슷한 약 10일)로 역산 — 보고서의 "최적 축제기간 역산 시뮬레이션"과 동일한 방식
- **전국 비교**: 전국 33개 관측지점의 평균 개화일과 위도 간 상관관계(r = 0.780) 분석, 창원(진해)은 전국 4위로 이른 개화 지역

## 📊 데이터 출처
